# Subcatica — История кошек

**Дипломный проект**
 
Интерактивное веб-путешествие по истории эволюции кошек: от современных домашних любимцев до их древних диких предков. Проект сочетает образовательный контент с плавными анимациями и сторителлингом, погружая пользователя в эволюционную хронологию семейства кошачьих.

**Демо:**  - https://subcatica-production.up.railway.app

---

## О проекте
 
Subcatica — это лонгрид-сайт с элементами scrollytelling, который проводит пользователя в обратном направлении по времени: от современной домашней кошки до её древних диких предков. Анимации, привязанные к скроллу страницы, помогают сделать изучение темы более наглядным и увлекательным.

## Возможности
 
- Интерактивная временная шкала происхождения кошачьих
- Интерактивная карта расселения кошачьих
- Плавные анимации и переходы на основе скролла (GSAP)
- Система лайков
- Тест с персонализированным результатом
- Адаптивный дизайн для разных устройств
- Серверная часть на Express с подключением к базе данных PostgreSQL

## Технологии
 
**Frontend**
- Vite — сборка и дев-сервер
- GSAP — анимации
- HTML / CSS / JavaScript

**Backend**
- Express — веб-сервер
- PostgreSQL (`pg`) — база данных
- dotenv — переменные окружения
